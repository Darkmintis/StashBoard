# StashBoard

Named, safe stashes for your unfinished git work.

Every stash is a real `git stash` entry — inspectable any time with plain
`git stash list`. Select files in the Changes list, right-click
**Save to Stash...**, browse your stashes in the Source Control sidebar, and
restore them with a safety net (apply-then-drop, never auto-drop on conflict).

Full readme, CLI docs, and the codebase live at the repository root:
<https://github.com/Darkmintis/StashBoard>
